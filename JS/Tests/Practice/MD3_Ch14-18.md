## Naming Convention

Each practice problem is kept in a separate `.js` file.

Example:

`44_Objects_Level1_01.js`

## Recommended Practice Order

1. Objects
2. Multi-Dimensional Arrays
3. Callback
4. Promise
5. Async/Await
6. Combined Challenges

## How to Run

From the folder:

```bash
node 44_Objects_Level1_01.js
```

For VS Code:
- Open the folder
- Open any `.js` file
- Use the integrated terminal
- Run `node filename.js`

## Practice Method

First read only the commented header and problem statement.

Then solve the TODOs yourself.

After solving:
1. Run the program.
2. Compare the output with the expected output.
3. Refactor using modern JavaScript.
4. Try a second solution using array methods where applicable.
